**Google Material sounds**
- Original page: https://material.io/design/sound/sound-resources.html ("Download this set of audio files for use in your own product", CC BY 4.0).
- Google's own download link (storage.googleapis.com/material-design/downloads/material_product_sounds.zip) now returns 403, so the files were taken unchanged from the mirror https://github.com/nana-4/materia-sound-theme (folder `material_product_sounds`), which keeps Google's attribution and licence.
- Licence text: https://creativecommons.org/licenses/by/4.0/legalcode

**Not used:** Google's Actions sound library (actions.google.com/sounds). Its terms limit it to Google Assistant Actions, so it can't go in a game.

**The font** (IBM Plex Sans Condensed, `Assets/Fonts`) is under the SIL Open Font License (`Assets/Fonts/OFL.txt`). It needs no credit, but the licence file has to ship with it.
